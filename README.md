# Battle Ramps — Homework Ninja Studios

Dit is de repository voor het Battle Ramps Unreal Engine-starterproject.

## Project downloaden

Download `BattleRampsUE_StarterProject.zip` uit deze repository via de bestandslink op GitHub en pak het archief lokaal uit.

## Benodigdheden

- Unreal Engine 5.8
- Xcode op macOS (voor C++ builds) of de relevante Visual Studio C++-toolchain op Windows
- Zie `README_NL.md` en `INSTALL_NL.txt` in het uitgepakte project voor Nederlandstalige instructies

## Belangrijk

Dit is broncode/starterproject, geen kant-en-klare .app of .exe. Je moet het project in Unreal Engine bouwen en testen. Het bevat procedurele placeholder-assets; hoogwaardige gelicentieerde modellen en materialen zijn nodig voor fotorealistische kwaliteit.
